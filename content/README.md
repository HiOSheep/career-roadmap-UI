# 职业规划档案内容

`archives.json` 为既有内容校验与纯文本导出接口保留的空白工作表数据，不包含真实人物经历、市场调研或职业结论。页面主体使用 `src/career-roadmap.ts` 中的 12 个月空白路线结构。

## 字段

每条记录保留稳定编号、标题、分类、范围、角色、状态、摘要、待填写事项和来源字段。初始内容只提示应填写的事实、贡献边界、限制及证据位置。来源字段可以写“待填写”；补入外部资料时，必须使用真实且可访问的 HTTP(S) 来源，并在正文记录日期、口径和限制。

## 修改与校验

修改 `archives.json` 后运行 `npm run check:content` 和 `npm run build`。`npm run export:archives` 会从该文件生成公开下载模板。生成内容应保持事实、分析、假设和未来计划清晰区分。
