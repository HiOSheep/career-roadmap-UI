# 职业规划输入工作表

此文件是配合 `evidence-driven-career-planner/SKILL.md` 使用的空白收集表。所有字段初始为空，不代表已有个人事实。按需要填写，避免在公开仓库中提交不愿公开的身份、联系方式、雇主内部材料或他人个人信息。

## 记录规则

- **事实**：能说明发生了什么，并可指出原始证据或来源。
- **分析**：基于事实得出的解释，应写出推理过程。
- **假设**：尚未验证的判断，标为“待验证”。
- **计划**：未来准备做的事，标为“计划”，不能写成已完成成果。
- 没有可靠证据的字段写“待核实”；不要用推测补齐数字。
- 对项目分别记录本人、团队成员、AI 或自动化的贡献，以及失败、限制和未验证部分。
